# Ошибки и как их не повторять

- 2026-10: PDFium `FPDFBitmap_CreateEx` с форматом BGR (2) давал чёрную полосу справа → использовать BGRx (3).
- 2026-10: `ReleaseCapture()` вызывал `WM_CAPTURECHANGED` и сбрасывал состояние до проверки клика по ссылке → сначала читать состояние, потом отпускать захват.
- 2026-10: постоянная перерисовка (≈270 кадров/с): каждая отрисовка заново запрашивала данные страницы, воркер уведомлял на каждое задание → запрашивать только если данных нет, уведомлять только о новом.
- 2026-10: встроенный поиск PDFium не сворачивает регистр кириллицы → собственный поиск с `CharLowerBuffW`.
- 2026-10: при восстановлении сессии вылезал запрос пароля у фоновой вкладки → откладывать до активации вкладки (`needPw`).
- 2026-10: разрывы кадра при прокрутке (таймер 15 мс без привязки к вертикальной развёртке; тайлы дорисовывались после остановки) → синхронизация по DwmFlush, потом DXGI-вывод, опережающая подгрузка по бюджету памяти.
- 2026-11-04: пароль к ключу чуть не записали в Drive-файл заглушкой «PWPLACEHOLDER» (инструмент Drive не умеет менять содержимое) → создавать файл сразу с настоящим паролем.
- Тесты под Wine: нужен `LANG=C.UTF-8` для Unicode-имён; окно больше Xvfb даёт чёрные снимки (Xvfb 1920×1080); не делать `pkill -f wine64` (убивает собственную оболочку).
