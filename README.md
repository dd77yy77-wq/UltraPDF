# UltraPDF (PDF Читалка)

Простой просмотрщик PDF для Android: WebView-интерфейс + системный PdfRenderer.
Пакет `com.dd.pdfviewer`, minSdk 21, targetSdk 34.

Возможности: ленивая отрисовка страниц (страницы отдаёт приложение напрямую в WebView, без передачи через JS), щипок и двойной тап для масштаба,
переход на страницу, ночной режим (инверсия страниц на стороне приложения), запоминание позиции, открытие последнего файла, открытие PDF из других приложений,
меню: открыть, история (10 последних документов), день/ночь, поиск по тексту (Android 15+, встроенный PdfRenderer), поделиться, сохранить как, о приложении (проверка обновлений, поделиться приложением, GitHub).
Тап по странице плавно прячет обе панели.

**Режимы.** В меню есть переключатель Pro. Обычный режим: открыть, история, день/ночь, поиск, поделиться, сохранить как, о приложении (как в 1.4). Режим Pro добавляет: закладки, оглавление, ссылки внутри документа, текст страницы (выделить и скопировать), печать, пароль на PDF, внешний вид (день/сепия/ночь, светлая или тёмная тема приложения, яркость экрана), полный экран (выход всегда виден крестиком в правом верхнем углу).

Для оглавления, ссылок и текста страницы внутри лежит pdf.js 3.11.174 (Apache-2.0, `assets/pdfjs/`), грузится только когда нужен.

Готовый APK: `UltraPDF.apk` (подпись ключом dbg.jks, тем же, что у TITAN RAID).
Автообновление: при запуске приложение читает `version.json` из этого репозитория (ветка main) и, если `code` больше установленного, предлагает скачать и установить `UltraPDF.apk`. Для новой версии увеличить `code`/`name` в `version.json` и заменить APK.

Сборка: `SDK=/path/to/sdkmin KS=/path/to/dbg.jks ./build.sh <versionCode> <versionName> out.apk`
(aapt2 → javac → d8 → zipalign → apksigner). Внутренние нестатические классы в Java не использовать: d8 8.2 на них падает.

Тесты (без телефона): `node tests/ui_test.js assets/index.html` (интерфейс на заглушке DOM), `node tests/pdfjs_helpers_test.js` (оглавление, ссылки, текст на настоящем pdf.js и `tests/fixture.pdf`), `python3 tests/e2e_browser.py /tmp/e2e` (настоящий Chromium через Playwright, приложение имитируется).
