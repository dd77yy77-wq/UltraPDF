# Щиток

Android-приложение: фото электрощитка с 12 автоматами и список, что за что отвечает.
Нажатие на автомат подсвечивает строку, нажатие на строку подсвечивает автомат.
Названия можно менять карандашом справа в строке, они хранятся на телефоне.
Пакет `com.dd.shchitok`, minSdk 24, targetSdk 34. Интерфейс: `assets/index.html` (WebView).

Готовый APK: `Shchitok.apk`. Автообновление: при запуске приложение читает `version.json` в этой папке
(ветка main) и, если `code` больше установленного, предлагает скачать и установить `Shchitok.apk`.
Для новой версии: увеличить `code`/`name` в `version.json` и заменить `Shchitok.apk`.

## Названия автоматов
Хранятся в `assets/index.html`, массив `DEFAULTS` (номер = позиция слева направо, с нуля).
Подписи, внесённые на телефоне карандашом, имеют приоритет над `DEFAULTS`.

## Сборка (без Android SDK)
Нужны только JDK и Python 3 с пакетами `Pillow` и `cryptography`.
1. `tools/setup_dx.sh` собирает dx (class -> dex) из исходников AOSP.
2. `python3 build.py <versionCode> <versionName> <out.apk>`

Подписывается ключом `keys/shchitok.p12` (пароль `android`, путь можно задать через `KEYDIR`).
Ключ в репозиторий не кладётся. Обновление ставится поверх только если подпись та же.
`build.py` сам собирает манифест, ресурсы, иконку, zip и подпись v1+v2 (`tools/apkbuild.py`).
Классы Android берутся из заглушек `stubs/`: сигнатуры сверены с рабочим dex UltraPDF (`tools/dexrefs.py`).
Нельзя использовать лямбды (dx их не поддерживает): только анонимные классы.
