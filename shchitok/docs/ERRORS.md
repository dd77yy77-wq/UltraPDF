# Ошибки и как их не повторять

- Подпись v2: неверный префикс длины → всегда проверять `A.v2_verify` и `jarsigner -verify`.
- Python `%`-форматирование ломалось на «%» в JS → подставлять через `.replace()`, не через `%`.
- Playwright: `Locator.screenshot(clip=...)` не поддерживается → делать `page.screenshot(clip=...)`.
- Схема слева: надписи перекрывали друг друга, провода касались шины N → проверять скриншотом 412×860 после каждой правки схемы.
- Предупреждающий треугольник перекрывал кнопку зума → позиция `warnAt`.
- Недопонимание «3й»: переспрашивать нумерацию автоматов, если неоднозначно.
- Ключ подписи лежал только в рабочей среде → теперь зашифрован в `keys/shchitok.p12.enc` (пароль у пользователя).
